# የSCTracker Native Apps የተጠቃሚ መመሪያ

## አማርኛ · የማጣቀሻ ትግበራ

ስሪት 0.1 — መስከረም 2026

> አስፈላጊ፦ የiOS እና Android መተግበሪያዎቹ ሊሰሩ የሚችሉ የማጣቀሻ ትግበራዎች ናቸው፤ የምርት ስርዓት፣ የደህንነት ማረጋገጫ፣ የሕግ ምክር ወይም ራስ-ሰር የEUDR ተገዢነት ውሳኔ አይደሉም።

## 1. ዓላማ እና የደህንነት ገደቦች

SCTracker መሣሪያው ከመስመር ውጭ ሲሆን የቡና ባች፣ ከረጢት፣ ማኅተም፣ ርክክብ፣ አካባቢ፣ የሚዲያ ማጣቀሻ እና የጥቅል ማረጋገጫ ይመዘግባል። ክስተቶች ሳይሰረዙ ይጨመራሉ እና በሃሽ ይያያዛሉ።

የማጣቀሻው ትግበራ የአካባቢ ፊርማ፣ የሕይወት ዑደት ሕጎች፣ የርክክብ ውሳኔ፣ ለይቶ ማቆያ እና የተረጋገጠ ጥቅል ልውውጥን ያሳያል። ለምርት የጀርባ ስርዓት ማንነት/ፈቃድ፣ የድርጅት እምነት/ስረዛ፣ ደህንነቱ የተጠበቀ ምዝገባ/መመለስ፣ ምስጠራ፣ ክትትል፣ የግላዊነት እና ገለልተኛ የደህንነት ግምገማ ያስፈልጋሉ። ሃሽ ወይም የመሣሪያ ፊርማ መረጃው እውነት ወይም ተጠቃሚው ፈቃድ እንዳለው አያረጋግጥም።

## 2. መጫን እና ማዋቀር

### Android

1. Android 8.0/API 26 ወይም ከዚያ በላይ እና የማያ መቆለፊያ ይጠቀሙ፤ በድርጅቱ የተፈቀደ የተፈረመ build ብቻ ይጫኑ።
2. ለልማት `mobile-native\android`ን በAndroid Studio፣ JDK 17 እና Android SDK 35 ይክፈቱ ወይም `.\gradlew.bat assembleDebug` ያስኪዱ።
3. አስፈላጊውን የካሜራ፣ አካባቢ፣ ፋይል እና NFC ፈቃድ ብቻ ይስጡ። ይህ ማጣቀሻ የሚዲያ/GPS ሞዴሎችን ይዟል ነገር ግን ሁሉንም የመያዝ ሂደት አላጠናቀቀም።
4. በራስጌው የከመስመር ውጭ ዝግጁነት እና ቋሚ የቋንቋ ምልክት ይፈትሹ።

### iOS

1. iOS 17 ወይም ከዚያ በላይ እና የመሣሪያ የይለፍ ቁጥር ይጠቀሙ፤ የተፈቀደ የተፈረመ build ብቻ ይጫኑ።
2. ለልማት `mobile-native\ios\SCTrackerNative.xcodeproj`ን በXcode 16 ወይም ከዚያ በላይ ክፈቱ እና `SCTrackerNative` scheme ይምረጡ።
3. በእውነተኛ iPhone NFC ለመጠቀም ትክክለኛ App ID እና NFC Tag Reading entitlement ያስፈልጋል። Simulator ለልማት ብቻ የሶፍትዌር ቁልፍ ይጠቀማል።
4. የዓለም ኳስ ምልክቱ በሁሉም ገጽ ራስጌ ላይ እንዳለ ያረጋግጡ።

የsimulator መረጃ፣ የልማት ቁልፍ፣ debug build ወይም የምሳሌ ተጠቃሚ ለምርት መዝገብ አይጠቀሙ።

## 3. የመሣሪያ ምዝገባ እና የእምነት ጥቅል

በመተግበሪያው ያሉ ተጠቃሚዎች፣ ሚናዎች እና የእምነት ሁኔታዎች ቦታ ያዦች ናቸው። በምርት አስተዳዳሪው መሣሪያውን ይመዘግባል፣ የሕዝብ ቁልፉን ከድርጅትና ከተሰየመ ኦፕሬተር ጋር ያስራል፣ የመሣሪያ/OS/app ስሪትና የቁልፍ ጥበቃን ይመዘግባል፣ ሚናና የማብቂያ ጊዜ ያለው የተፈረመ የእምነት ጥቅል ይሰጣል፣ ስረዛንም ይደግፋል።

ሥራ ከመጀመርዎ በፊት የመሣሪያ ID፣ የቁልፍ ID፣ ድርጅት፣ ኦፕሬተር፣ ሚና፣ ጊዜ እና ፊርማ ይፈትሹ። `UNVERIFIED`፣ `LOCALLY_TRUSTED`፣ `ORGANIZATION_VERIFIED` እና `REVOKED` የፕሮቶኮል መለያዎች ናቸው፤ ፈቃድ የሚሰጠው የድርጅት ፖሊሲ ብቻ ነው። ጊዜው ያለፈ፣ የማይታወቅ፣ የማይዛመድ ወይም የተሻረ ጥቅል ውድቅ ያድርጉ።

## 4. ቋንቋ መምረጥ

በላይኛው ራስጌ ያለውን ቋሚ የዓለም ኳስ/ቋንቋ ምልክት ይንኩ እና Deutsch፣ English፣ አማርኛ ወይም ትግርኛ ይምረጡ። ምርጫው በመሣሪያው ላይ ይቀመጣል። መለያዎች፣ ሃሾች፣ ኮዶች፣ የቦታ/ሰው ስሞች እና የፕሮቶኮል እሴቶች አይተረጎሙም፤ ገላጭ ጽሑፍ ይተረጎማል።

## 5. ከመስመር ውጭ ዝግጅት

- መሣሪያውን ይሙሉ እና በቂ የተጠበቀ ማከማቻ ያረጋግጡ።
- Appን ይክፈቱ፣ ቋንቋ ይምረጡ፣ የኦፕሬተር/መሣሪያ እምነት ይፈትሹ።
- በምርት የተመደበውን ሥራ እና የተፈቀደውን የእምነት ጥቅል ያውርዱ።
- ቀን/ሰዓት፣ ካሜራ፣ አካባቢ እና ፈቃዶችን ይፈትሹ።
- ደህንነቱ የተጠበቀ የጥቅል ማስተላለፊያ እና የወረቀት አማራጭ ያዘጋጁ።
- NFC ላይ አይተማመኑ፤ እውነተኛ የቺፕ ስራዎች ሆነው ታግደዋል።

“ከመስመር ውጭ ዝግጁ” ማለት የአካባቢ ሂደት ይሰራል ማለት ብቻ ነው፤ ማንነት፣ እምነት፣ ምትኬ እና ማመሳሰል ተጠናቋል ማለት አይደለም።

## 6. የኦፕሬተር ማረጋገጫ

የማጣቀሻ app የምርት login የለውም። ምርት በድርጅት የተሰጠ ማንነት፣ የመሣሪያ መክፈቻ፣ አጭር የእንቅስቃሴ ማቆሚያ፣ በሚና የተመሠረተ ፈቃድ እና ለስሱ ማስተካከያ የተቆጣጣሪ ፈቃድ ሊያስገድድ ይገባል። ማስረጃ አያጋሩ፣ የተከፈተ መሣሪያ አይተዉ። የታየው ኦፕሬተር፣ ድርጅት ወይም ሚና ስህተት ከሆነ ሥራ ያቁሙ።

## 8. የGPS ጥራት

ከቤት ውጭ ሰማይ በግልጽ ቦታ ይያዙ። የተረጋጋ fix ይጠብቁ እና አግድም ትክክለኛነት፣ provider፣ ጊዜ እና mock-location ምልክትን ይፈትሹ። ማጣቀሻው 25 ሜትር ወይም የተሻለን ይቀበላል፤ የምርት ፖሊሲ የበለጠ ጥብቅ ሊሆን ይችላል። ደካማ መለኪያን ይድገሙ እና ያልተገኘውን ያብራሩ። GPS ማስረጃ መረጃ እንጂ የመነሻ ማረጋገጫ አይደለም፤ ኮርዲኔት አይፍጠሩ፣ አያጠጋጉ ወይም ከሌላ ቦታ አይቅዱ።

## 9. የሕይወት ዑደት፣ ቁጥጥር፣ ጉዳት፣ መክፈት እና ማስተካከያ

መደበኛ ቅደም ተከተል `UNISSUED` → `ISSUED` → `SEALED` → `IN_TRANSIT` → `OPENED` ነው። `VOID` እና `DAMAGED` የመጨረሻ ልዩ ሁኔታዎች ናቸው።

- Genesisና ከረጢቶችን ከፈተሹ በኋላ Issue ያድርጉ።
- የተፈቀደውን የማኅተም ሂደት ከፈተሹ በኋላ Seal ያድርጉ።
- ርክክብ/ጭነት መረጃ ትክክል ሲሆን ብቻ transit ይጀምሩ።
- በተፈቀደው መድረሻ ብቻ Open ያድርጉ እና ማስረጃ ይመዝግቡ።
- ከረጢት/ማኅተም ከተጎዳ `DAMAGED` ያድርጉ፣ ስራ ያቁሙ እና ለይቶ ማቆያ ይከተሉ።
- ጥቅም ላይ የማይውል መለያ `VOID` ያድርጉ።
- ታሪክን አይተኩ፤ ማስተካከያ የተሳሳተውን መዝገብ የሚጠቅስ አዲስ የተፈረመ ክስተት ነው።

## 10. OFFER፣ ACCEPT፣ REJECT እና PENDING

`OFFER` ርክክቡን `PENDING` ያደርጋል፤ በዚህ ጊዜ ጥበቃ/ባለቤትነት አልተላለፈም። ተቀባዩ የባች/ከረጢት መለያ፣ ላኪ፣ ተቀባይ፣ ሁኔታ እና ትክክለኛ offer hash ይፈትሻል። `ACCEPT` ወይም `REJECT` ያንኑ ሃሽ መጥቀስ አለበት። ሁለተኛ ውሳኔ ወይም የማይዛመድ ሃሽ ይከለከላል። ግጭት ወይም ተመሳሳይ ርክክብ ሲኖር ለተቆጣጣሪ ግምገማ በPENDING/ለይቶ ማቆያ ይቆይ።

## 11. የፎቶ እና ሰነድ ማስረጃ

መለያ፣ ማኅተም፣ ሁኔታ እና የተፈቀዱ ሰነዶችን ግልጽና ሙሉ አድርገው ያንሱ። ያልተያያዙ ሰዎች፣ ID፣ ስክሪን ወይም የግል አካባቢ አይካተት። focus፣ ሙሉነት፣ ጊዜ፣ የባች ግንኙነት፣ MIME type፣ መጠን እና SHA-256 ይፈትሹ። ማጣቀሻው ሜታዳታና ሃሽ ይይዛል እንጂ ሙሉ የተጠበቀ ሚዲያ ማከማቻ አይደለም። ምርት ምስጠራ፣ retry፣ malware scan፣ የማቆያ/ስረዛ ፖሊሲ እና መዳረሻ ቁጥጥር ይፈልጋል።

## 12. ለይቶ ማቆያ፣ ግጭት እና ግምገማ

ፊርማ፣ ሃሽ፣ sequence፣ previous hash፣ ማንነት/እምነት፣ የሕይወት ዑደት፣ ማስረጃ ወይም አካላዊ ሁኔታ ማረጋገጥ ካልተቻለ ባች/ጥቅሉን ለይተው ያቆዩ። የተለያዩ የክስተት ቅርንጫፎች ራስ-ሰር አይቀላቀሉም። ሁለቱንም ያቆዩ፣ የስህተት ኮድ ይመዝግቡ፣ ሥራ ያቁሙ እና ያሳውቁ። “ተገምግሟል” ማለት በማጣቀሻው ግምገማ ብቻ ነው፤ ምርት ፈቃድ ያለው የተቆጣጣሪ የተፈረመ የማስተካከያ ውሳኔ ይፈልጋል።

## 13. ጥቅል መላክ፣ ማስገባት እና ማረጋገጥ

ለመላክ “የተፈረመ export” ይምረጡ፣ ጥቅሉን አይቀይሩ እና በተፈቀደ መንገድ ያስተላልፉ። ለማስገባት “import and verify” ይምረጡ። ከመቀበል በፊት manifest ቅርጽ/ፊርማ፣ ትክክለኛ ፋይሎች፣ ደህንነቱ የተጠበቀ path፣ byte size፣ ሁሉም SHA-256፣ chain root፣ event chain እና signature ይፈተሻሉ።

ከፊል አያስገቡ፣ ፋይል አይቀይሩ፣ ስህተትን አይዝለሉ፣ የጥቅል ፊርማንም እንደ ድርጅት እምነት አይቁጠሩ። የማይሰራ/የሚጋጭ ጥቅል በለይቶ ማቆያ ይቆይ። ምርት የመጠን ገደብ፣ streaming archive፣ recipient encryption፣ malware/media scan፣ trusted-key lookup፣ replay control እና audit sync ይፈልጋል።

## 14. የስህተት ኮዶች እና የኦፕሬተር ምላሽ

- `SCT-INPUT` / `GENESIS_SACK_COUNT_INVALID`፦ የጎደለ ግቤት ወይም 1–100 ብዛት ያስተካክሉ።
- `SCT-STATE` / `TRANSITION_NOT_ALLOWED`፦ መዝገቡን ያድሱ እና የተፈቀደ እርምጃ ብቻ ይውሰዱ።
- `SCT-EVENT`፦ ያቁሙ እና መረጃውን ያቆዩ፤ duplicate፣ sequence፣ hash ወይም chain ችግኝ አለ።
- `SCT-SIGN` / `KEYSTORE_UNAVAILABLE`፦ ፊርማ ያቁሙ፤ ምዝገባና የቁልፍ ጥበቃ ይፈትሹ።
- `SCT-PACKAGE` / `MANIFEST_*`፦ አያስገቡ፤ ጥቅሉን ለይተው ያቆዩ እና hash ያሳውቁ።
- `SCT-CONFLICT` / `IMPORT_QUARANTINED`፦ የባች ሥራ ያቁሙ እና ፈቃድ ያለው እርቅ ይጠይቁ።
- `SCT-STORAGE`፦ ሥራ ያቁሙ፣ መሣሪያውን ያቆዩ፣ app data አይሰርዙ።
- `SCT-CHIP` / `SCT-NFC`፦ እንደ እውነተኛነት ማስረጃ አይድገሙ፤ የተፈቀደ non-NFC አማራጭ ይጠቀሙ።

ትክክለኛ ኮድ፣ ጊዜ፣ የመሣሪያ ID፣ የባች/ርክክብ/ጥቅል ID እና እርምጃ ይመዝግቡ። ሚስጥር፣ ሙሉ የግል መረጃ፣ APDU ወይም የቺፕ ምላሽ ለsupport አይላኩ።

## 15. ግላዊነት እና የጠፋ መሣሪያ

አስፈላጊ መረጃ ብቻ ይሰብስቡ። password፣ secret key፣ የማያስፈልግ የግል መረጃ፣ ሙሉ የሰነድ ምስል ወይም ትክክለኛ coordinate በnote፣ log፣ chat ወይም ህዝባዊ ስርዓት አያስቀምጡ።

መሣሪያው ከጠፋ/ከተሰረቀ ወዲያውኑ ያሳውቁ፤ የመሣሪያ ቁልፍና የእምነት ጥቅል ይሰረዙ፤ session ይዝጉ፤ የመጨረሻ የታመነ checkpoint ይለዩ፤ ቀጣይ ያልታመነ እንቅስቃሴን ለይተው ያቆዩ፤ በፖሊሲ ብቻ remote lock/erase ያድርጉ። አዲስ መሣሪያ እንደ አዲስ ይመዝገብ፤ የፊርማ ቁልፍ ከbackup አይቅዱ።

## 16. ችግኝ መፍትሔ

- App ካልተከፈተ፦ OS፣ storage፣ signature እና device policy ይፈትሹ፤ ማስረጃ ከመጠበቅ በፊት reinstall አያድርጉ።
- ቋንቋ ከተሳሳተ፦ ቋሚ globe icon ይጠቀሙ።
- አካባቢ ካልተገኘ፦ ወደ ውጭ ይውጡ፣ permission ይክፈቱ፣ accuracy ይጠብቁ እና fallback ይመዝግቡ።
- Import ካልሰራ፦ ዋናውን ጥቅል ሳይቀይሩ ያቆዩ፣ hash እና code ያሳውቁ።
- History ከተጋጨ፦ ሥራ ያቁሙ እና quarantine ያድርጉ፤ ቅርንጫፍ በእጅ አይምረጡ።
- NFC ካልሰራ፦ በተላከው disabled profile የሚጠበቅ ነው፤ የተፈቀደ fallback ይጠቀሙ።
- Signing/storage ካልሰራ፦ ሥራ ያቁሙ፣ app data አይሰርዙ እና የመሣሪያ ሰዓት አይቀይሩ።

## 17. አስገዳጅ የNFC ማስጠንቀቂያ

> እውነተኛ የNFC ማንነት ማረጋገጥ፣ READ፣ UPDATE እና READ-BACK መታገድ አለበት፤ የተፈቀደ የአምራች-ተኮር PoC ቺፕንና memory/application layoutን እስኪለይ፣ ኦፊሴላዊ APDU/status word እስኪጠቀም፣ በapp ውስጥ ያልተቀመጠ secure key provisioning/diversification/rotation/revocation እስኪወስን፣ iOS/Android compatibility እስኪያረጋግጥ፣ replay፣ relay፣ cloning፣ tearing፣ interruption፣ lockout፣ damage እና read-back እስኪፈትሽ እና ገለልተኛ የደህንነት ግምገማ እስኪያልፍ ድረስ።

Repositoryው የተፈቀደ የምርት chip profile፣ APDU set ወይም provisioning key የለውም። UID ለፍለጋ ብቻ ነው፤ የእውነተኛነት ማስረጃ አይደለም።
